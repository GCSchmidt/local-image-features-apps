# local-image-features-apps
This is a project where I implement solutions leveraging local image features to accomplish the following applications:
1. Image Stitching
2. Object detection
3. Object/Motion Tracking
4. Indexing and Database Retrieval
5. 3D Reconstruction
6. Robot Navigation

## Setup
Follow the following steps after cloning the repo:

```
python3 setup.py && source .venv/bin/activate
```
